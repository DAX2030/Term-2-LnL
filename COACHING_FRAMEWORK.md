# Term 2 L&L — Coaching Framework & Best Practices

## Student Goals
- Learn, test, and excel across all Term 2 syllabus topics
- Uncover weak spots and blindspots through iterative testing
- Build deep conceptual understanding, not shallow memorisation

## Coaching Method

### Question Types Per Round
1. **5 MCQs** — drawn from across all topics; not shallow or obviously wrong options
2. **1–2 Subjective Questions** — require written responses; assessed against a rubric
3. Questions **prioritised from worksheet tasks and revision materials** in the syllabus files

### MCQ Design Rules
- Options must all be plausible — no obviously wrong answers
- Test application and analysis, not just definition recall
- Rooted in actual texts: Barkhad Abdi, Malala, Mandela, *The Road Not Taken*, *Night Mail*, persuasive speech examples
- Drawn from question types that appeared in worksheets and class activities

### Subjective Question Design Rules
- May blend multiple topics (e.g., writer's voice + literary techniques in a biography)
- Always accompanied by a rubric
- Word limits aligned to MYP style responses

---

## Rubric Template (Subjective Questions)

| Score | Descriptor |
|-------|-----------|
| 4/4 | Precise use of terminology; specific textual evidence; clear explanation of effect; insightful analysis beyond surface meaning |
| 3/4 | Correct terminology; relevant evidence; explanation present but effect not fully developed |
| 2/4 | Some correct terminology; evidence present but explanation is vague or incomplete |
| 1/4 | Basic attempt; limited terminology; evidence missing or irrelevant |
| 0/4 | No relevant response |

---

## Iterative Feedback Loop
1. Student answers MCQs + subjective questions
2. Coach scores and identifies weak spots
3. Next round **prioritises those weak spots** — harder questions on those exact concepts
4. Blindspots flagged explicitly: "You keep missing X — here's why it matters"
5. Progress tracked across rounds

## Best Practices for This Student
- **Mix topics every round** — don't isolate chapters; exam won't either
- **Prioritise worksheet-style questions** — these most closely reflect exam format
- **Push beyond definitions** — always ask "what effect does this create?" or "why has the writer chosen this?"
- **Use actual texts** — ground every question in the student's own materials
- **Track errors across rounds** — build a weak-spot log and revisit systematically
- **Rubric always visible** — student must know the standard before writing
